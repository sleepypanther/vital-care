# Patient Smartwatch App

- Wear OS: Kotlin + Jetpack Compose (glanceable UI)
- watchOS: SwiftUI (glanceable UI)

Screens:
- Home (HR, SpO2, Steps, Time, SOS)
- Vitals (HR, Resting HR, SpO2, HRV, Resp, Sleep)
- Medication (Take/Snooze/Remind)
- Emergency (SOS, "Are you OK?" with timeout)

No phone UI shrink. Large targets. Low battery. Deterministic emergency flow.
